# Cmd Code VSC
Cmd Code VSC/cmdcode-vsc is an extension for Visual Studio Code that adds Command Code as a Language Model Provider to VS Code fur use in VS Code's AI/LLM dependant features, like Copilot, etc.
In addition to providing the Language Model Provider for the VSCode features, which is only possible via Command Code API on Provider, Goat and higher plans, this extension also integrates Command Code with VS Code at a basic level so Go plan users (Go only works for Command Code's terminal agent) can also utilize Command Code in VSC to some extent, if not the max.
